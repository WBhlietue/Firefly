## Функцын онцлог

⚡ Статик сайт үүсгэх: Astro-д суурилсан хэт хурдан ачаалалт болон SEO оновчлол

🎨 Орчин үеийн загвар: Энгийн гоёмсог интерфэйс, өөрийн загварын өнгийг тохируулах боломжтой

📱 Мобайлд ээлтэй: Төгс responsive туршлага, мобайлд тусгайлан оновчлосон

🔧 Өндөр тохируулга: Ихэнх функцын модулийг тохиргооны файлаар өөрчлөх боломжтой

### Үндсэн функцууд

- [x] **Astro + Tailwind CSS** - Орчин үеийн технологийн стек дээр суурилсан хэт хурдан статик сайт үүсгэлт
- [x] **Гөлгөр animation** - Swup хуудас шилжилтийн animation, тухтай үзэх туршлага
- [x] **Responsive загвар** - Десктоп, таблет болон мобайл төхөөрөмжид төгс зохицно
- [x] **Олон хэлний дэмжлэг** - i18n интернационалчлал, UI нь хятад хялбар, хятад уламжлалт, англи, япон, орос, солонгос хэлийг дэмжинэ
- [x] **Бүрэн текст хайлт** - Pagefind дээр суурилсан клиент талын хайлт, өгүүллийн агуулгын индекслэлтийг дэмжинэ

### Хувийн тохиргоо
- [x] **Динамик хажуугийн самбар** - Нэг талт, хоёр талт хажуугийн самбарыг тохируулах боломжтой
- [x] **Өгүүллийн байрлал** - Жагсаалт (нэг багана), grid (олон багана/waterfall) байрлалыг тохируулах боломжтой
- [x] **Фонт удирдлага** - Өөрийн фонт тохируулах боломжтой, баялаг фонт сонгогч
- [x] **Footer тохиргоо** - HTML агуулга оруулах, бүрэн тохируулах боломжтой
- [x] **Гэрэл/харанхуй горим** - Гэрэл, харанхуй, системийг дагах гэсэн гурван горимыг дэмжинэ
- [x] **Навигацийн мөр тохируулга** - Logo, гарчиг, холбоосыг бүрэн тохируулна
- [x] **Wallpaper горим солих** - Banner wallpaper, бүрэн дэлгэцийн wallpaper, бүрэн дэлгэцийн тунгалаг wallpaper, цул өнгийн дэвсгэр
- [x] **Загварын өнгийн тохиргоо** - 360° hue тохируулга

Хэрэв танд хэрэгтэй функц эсвэл оновчлол байвал [Pull Request](https://github.com/CuteLeaf/Firefly/pulls) илгээнэ үү

## Хурдан эхлэх

### Орчны шаардлага

- Node.js ≥ 22
- pnpm ≥ 11

### Локал хөгжүүлэлт ба deploy

1. **Репозиторийг clone хийх:**
   ```bash
   git clone https://github.com/Cuteleaf/Firefly.git
   cd Firefly
   ```

   **Эхлээд өөрийн репозитор руу [Fork](https://github.com/CuteLeaf/Firefly/fork) хийгээд clone хийхийг зөвлөж байна, Star дараад Fork хийнэ үү!**

   ```bash
   git clone https://github.com/you-github-name/Firefly.git
   cd Firefly
   ```
3. **Хамаарал суулгах:**
   ```bash
   # Хэрэв pnpm суулгаагүй бол эхлээд суулгана
   npm install -g pnpm

   # Төслийн хамаарлыг суулгах
   pnpm install
   ```

4. **Блог тохируулах:**
   - `src/config/` доторх тохиргооны файлыг засаж блогийн тохиргоог өөрчилнө

5. **Хөгжүүлэлтийн серверийг эхлүүлэх:**
   ```bash
   pnpm dev
   ```
   Блог нь `http://localhost:4321` дээр ажиллана

### Платформ дээр байршуулах
- **[Албан ёсны гарын авлага](https://docs.astro.build/zh-cn/guides/deploy/)-ыг дагаж блогийг Vercel, Netlify, Cloudflare Pages, EdgeOne Pages зэрэгт байршуулна.**
- **Vercel**, **Netlify** зэрэг тэргүүлэх платформууд автоматаар deploy хийнэ, орчноос хамааран тохирох адаптерыг автоматаар сонгоно.

    Framework preset: `Astro`

    Root: `./`

    Output: `dist`

    Build команд: `pnpm run build`

    Install команд: `pnpm install`
