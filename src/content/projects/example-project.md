## Төслийн үзүүллэгийн хуудасны гарын авлага

`src/content/projects/` дотор `.md` эсвэл `.mdx` файл шинээр үүсгэхэд л төсөл бүрдэнэ. **Үндсэн хэсэг нь төслийн README** бөгөөд дэлгэрэнгүй хуудасны доод хэсэгт дүрслэгдэнэ; харин **frontmatter** доторх талбарууд нь жагсаалтын карт болон дэлгэрэнгүй хуудасны дээд хэсэгт харагдана.

## Frontmatter талбарууд

| Талбар | Төрөл | Тайлбар |
|---|---|---|
| `title` | string | Заавал. Төслийн нэр. |
| `slug` | string | Сонголтоор, өгүүллийн адил ашиглана. |
| `published` | date | Заавал. Нийтэлсэн/шинэчилсэн огноо, жишээ нь `2025-10-01`. Эрэмбэлэхэд ашиглана (`order`-той хамт). |
| `draft` | boolean | Сонголтоор, өгөгдмөл `false`. `true` болговол production build-д энэ хуудас нуугдаж, preview-д харагдана. |
| `order` | number | Сонголтоор. Гар аргаар эрэмбэлэх жин, **их байх тусам урагш гарна**; тохируулаагүй бол `published`-аар буурахаар эрэмбэлнэ. |
| `description` | string | Сонголтоор. Картын товч танилцуулга + дэлгэрэнгүй хуудасны тайлбар. |
| `image` | string | Сонголтоор. Хавтасны зураг. Бүрэн URL, нийтийн root зам (`/images/xxx.png`), харьцангуй зам (энэ файлын хавтастай харьцангуй, жишээ нь `images/xxx.png`)-ыг дэмжинэ. Хоосон бол хавтасны зураг харагдахгүй. |
| `tags` | string[] | Сонголтоор. Шошго, жагсаалт болон дэлгэрэнгүй хуудсанд `#шошго` хэлбэрээр харагдана. |
| `link` | array | Сонголтоор. Гадны холбоосын товчнуудын массив: `{ label, icon, value }`. `icon` нь astro-icon нэр (жишээ нь `fa7-brands:github`), зургийн URL, эсвэл хоосон бол `label`-ийн эхний үсгийг ашиглана. |
| `status` | string | Сонголтоор. Төслийн төлөв, стандарт key ашиглана (доорх хүснэгтийг үзнэ үү). |
| `lang` | string | Сонголтоор. Хуудасны хэл, жишээ нь `zh_CN`. |

## Төлөвийн түлхүүр утгууд (status)

`status` нь **стандарт key** ашиглах бөгөөд интерфэйс нь сайтын хэлээр локалчлагдсан текстээр харуулж, төлөвөөр автоматаар өнгө + icon өгнө:

| key | Утга | Локалчлалын жишээ |
|---|---|---|
| `planning` | Төлөвлөж байгаа | Төлөвлөж байгаа / Planning |
| `developing` | Хөгжүүлж байгаа | Хөгжүүлж байгаа / In Development |
| `published` | Нийтлэгдсэн | Нийтлэгдсэн / Published |
| `archived` | Архивласан | Архивласан / Archived |

- Зөвхөн стандарт key бичихэд хангалттай: `status: "published"`.
- Танихгүй эсвэл өөрийн тодорхойлсон тэмдэгт мөр нь байгаагаар нь (саармаг саарал) харагдах бөгөөд жагсаалтын хуудасны төлөвийн шүүлтэд оролцохгүй.

> Жагсаалтын хуудасны дээд хэсэг нь **төлөвөөр шүүх** (бүгд / тус бүр төлөв) боломжийг дэмжих бөгөөд нэр, тайлбар, шошгоор төслийг **хайх** боломжтой.
