## 📖 Тойм

Firefly нь уян хатан байрлалын системийг санал болгож, та агуулгын шаардлага болон хувийн хүслээрээ блогийн харагдах байдлыг өөрчлөх боломжтой. Байрлалын систем нь үндсэндээ **хажуугийн самбарын байрлал** болон **өгүүллийн жагсаалтын байрлал** гэсэн хоёр хэмжээстэй бөгөөд тэдгээр нь харилцан уялдаж хуудасны ерөнхий бүтцийг тодорхойлно.

Энэ өгүүлэл Firefly-ийн төрөл бүрийн байрлалын горим, тэдгээрийн онцлог, хэрэглэх нөхцөл, мөн өөр өөр байрлалын хослолын үр дүнг дэлгэрэнгүй танилцуулна.

## Нэгдүгээр хэсэг, хажуугийн самбарын байрлалын систем

Хажуугийн самбар нь блогийн хуудасны чухал хэсэг бөгөөд навигаци, ангилал, шошго, статистик зэрэг туслах агуулгыг харуулахад ашиглагдана. Firefly нь хажуугийн самбарын хоёр байрлалын горимыг дэмжинэ.

### 1.1 Нэг талын хажуугийн самбарын горим

#### Зүүн хажуугийн самбар (position: "left")

![Зүүн хажуугийн самбарын байрлал](../images/left-list.avif)

#### Баруун хажуугийн самбар (position: "right")

![Баруун хажуугийн самбарын байрлал](../images/right-grid2.avif)

#### Онцлог

- Хажуугийн самбар нь хуудасны нэг талд тогтмол байрлана
- Өгүүлэл унших хэсэг нь илүү сайн, илүү өргөн туршлагатай
- Илүү энгийн, тийм ч нягт биш

#### Хэрэглэх нөхцөл

- Уламжлалт блогийн хэв маяг
- Навигаци болон ангилалыг онцолсон блог
- Хэрэглэгчийн профайлыг тодруулах шаардлагатай хувийн блог
- Агуулга нь тэргүүлэх, туслах мэдээлэл хоёрдугаарт орох нөхцөл

:::tip
Өгүүллийн дэлгэрэнгүй хуудсанд аль тал харагдахыг **компонент бүрийн `showOnPostPage` (болон `hideOnNonPostPage`)** тодорхойлно: тухайн талд энэ хуудасны төрөлд харагдах компонент байхгүй бол тэр багана автоматаар эвхэгдэж, зайг агуулгын баганад үлдээнэ.

Хэрэв өгүүллийн хуудсанд хоёр талын хажуугийн самбарыг зэрэг харуулахыг хүсвэл `position`-ыг `"both"` болгож, хоёр талын компонентод `showOnPostPage`-ыг тохируулна.
:::


#### Тохиргооны жишээ

```typescript
// src/config/sidebarConfig.ts
export const sidebarLayoutConfig: SidebarLayoutConfig = {
  enable: true,
  position: "left", // зүүн хажуугийн самбар
};
```

### 1.2 Хоёр талын хажуугийн самбарын горим (position: "both")

#### Онцлог

- Зүүн, баруун хоёр талд зэрэг хажуугийн самбар байна
- Үндсэн агуулгын хэсэг дунд байрлана
- Дэлгэцийн зайг хамгийн их ашиглана
- Илүү их туслах мэдээлэл харуулах боломжтой
- Өргөн дэлгэцтэй мониторт тохиромжтой

#### Байрлалын бүтэц

![Хоёр талын хажуугийн самбар + жагсаалтын байрлал](../images/both-list.avif)

![Хоёр талын хажуугийн самбар + grid байрлал](../images/both-grid.avif)
#### Хэрэглэх нөхцөл

- Өргөн дэлгэцтэй десктопоор үзэх
- Мэдээлэл ихтэй блог
- Их хэмжээний туслах агуулга харуулах шаардлагатай
- Мэргэжлийн өндөр түвшний техникийн блог


#### Тохиргооны жишээ

```typescript
// src/config/sidebarConfig.ts

  enable: true,
  position: "both", // хоёр талын хажуугийн самбар
```

## Хоёрдугаар хэсэг, өгүүллийн жагсаалтын байрлалын систем

Өгүүллийн жагсаалт нь блогийн нүүр болон архив хуудасны гол агуулга бөгөөд Firefly нь хоёр төрлийн харуулах аргыг санал болгож, олон төрлийн grid тохиргоог дэмжинэ.

### 2.1 Жагсаалтын горим (defaultMode: "list")

#### Онцлог

- Нэг баганаар босоо байрлана
- Өгүүллийн хавтас зургийг харуулах бөгөөд зүүн эсвэл баруун талд байрлуулж тохируулж болно
- Илүү их өгүүллийн товчлол харуулна
- Гүнзгий уншихад тохиромжтой

#### Жагсаалтын байрлалын бүтэц

![Жагсаалтын горимын байрлал](../images/left-list.avif)

#### Хавтас зургийн байрлал

Жагсаалтын горимд хавтас зураг өгөгдмлөөр картын баруун талд байх бөгөөд `coverPosition`-оор зүүн талд шилжүүлж болно. Зүүн талд шилжүүлсний дараа гарчгийн өмнөх сэдвийн өнгийн босоо шугам автоматаар нуугдана (энэ нь картын зүүн ирмэгт наалдсан загвар учраас), чөлөөлөгдсөн зай нь үндсэн хэсэгт үлдэнэ.

Grid горимд хавтас зураг картын дээд хэсэгт тогтмол байх бөгөөд энэ тохиргооноос хамаарахгүй.

#### Давуу тал

- ✅ Харааны нөлөө хүчтэй, хавтас зураг анхаарал татна
- ✅ Илүү их өгүүллийн мэдээлэл харуулах боломжтой (товчлол, шошго г.м.)
- ✅ Зургийн агуулга баялаг блогт тохиромжтой
- ✅ Мобайлд ээлтэй, нэг багана нь уншихад хялбар
- ✅ Бүх хажуугийн самбарын тохиргоотой нийцнэ (нэг тал, хоёр тал)

#### Тохиргооны жишээ

```typescript
// src/config/siteConfig.ts
export const siteConfig: SiteConfig = {
  postListLayout: {
    defaultMode: "list",    // жагсаалтын горим
    coverPosition: "right", // хавтас зургийн байрлал: "right" баруун, "left" зүүн
  },
};
```

---

### 2.2 Grid горим (defaultMode: "grid")

#### Онцлог

- Дасан зохицох баганын тоо, хөтчийн өргөнөөс хамааран автоматаар тохируулна
- Нягт байрлал, мэдээллийн нягтрал өндөр
- Хурдан үзэхэд тохиромжтой

#### Дасан зохицох grid

Grid горимд `columnWidth`-аар картын хамгийн бага өргөнийг (нэгж px) тохируулах бөгөөд хөтөч нь савны боломжтой өргөнөөс хамааран хэдэн багана багтахыг автоматаар тооцоолно.

![Grid байрлал](../images/left-grid3.avif)

#### Тохиргооны жишээ

```typescript
// src/config/siteConfig.ts
export const siteConfig: SiteConfig = {
  postListLayout: {
    defaultMode: "grid",
    grid: {
      masonry: true,      // masonry идэвхжүүлэх
      columnWidth: 320,   // картын хамгийн бага өргөн(px), хөтөч баганын тоог автоматаар тооцоолно
    },
  },
};
```

---

### 2.3 Masonry байрлал (Masonry)

Firefly-ийн grid горимд ухаалаг masonry байрлалын дэмжлэг суурилуулсан бөгөөд grid байрлалд зураг, текст холилдсон өгүүллийн улмаас картын өндөр ялгаатай болж үүсдэг хоосон зайг шийдвэрлэнэ.

![Masonry байрлал](../images/masonry.avif)

- **Ухаалаг байрлуулалт**：Картыг хамгийн богино баганад автоматаар байрлуулж, босоо зайг хамгийн их ашиглана.
- **Хоосон зайг арилгах**：Карт бүрийн байрлалыг absolute байрлалаар нарийн тооцоолж, картыг дээрх картад наалдуулан босоо чиглэлийн хоосон зайг арилгана.
- **Дасан зохицох баганын тоо**：Masonry нь ч мөн `columnWidth` болон савны өргөнөөс хамааран баганын тоог динамикаар тооцоолох тул тогтмол тохиргоо шаардлагагүй.
- **Уян хатан тохиргоо**：Та `siteConfig.ts` доторх `postListLayout.grid.masonry` сонголтоор энэ функцийг чөлөөтэй асаах, унтраах боломжтой.

## Гуравдугаар хэсэг, байрлалын хослолын гарын авлага

Firefly нь хажуугийн самбар болон өгүүллийн жагсаалтын байрлалыг чөлөөтэй хослуулах боломжийг олгоно. Доорх нь төрөл бүрийн хослолын үр дүнгийн тайлбар юм.

| Хажуугийн самбарын горим | Өгүүллийн жагсаалтын горим | Зөвлөмж | Хэрэглэх нөхцөл |
|-----------|------------|--------|---------|
| Нэг тал   | Жагсаалтын горим | ⭐⭐⭐⭐⭐ | Гэрэл зураг, дизайн, амьдралын блог, зургийг онцолсон |
| Нэг тал   | Grid горим | ⭐⭐⭐⭐⭐ | Техник, тэмдэглэлийн блог, унших ба хайх тэнцвэр |
| Хоёр тал  | Жагсаалтын горим | ⭐⭐⭐⭐⭐ | Хажуугийн самбарын их мэдээлэл харуулах шаардлагатай сайт |
| Хоёр тал  | Grid горим | ⭐⭐⭐⭐⭐ | Geek хэв маяг, хамгийн өндөр мэдээллийн нягтрал |

## Дөрөвдүгээр хэсэг, responsive байрлалын зан төлөв

Firefly-ийн байрлалын систем нь ухаалаг responsive загвартай бөгөөд дэлгэцийн хэмжээнээс хамааран автоматаар тохируулна.

Уншихад хамгийн сайн туршлагыг хангахын тулд систем нь дэлгэц нарийсах үед байрлалыг автоматаар тохируулна:

1. **Grid баганын тоо автоматаар багасах**：Grid горимын баганын тоо нь `columnWidth` болон савны өргөнөөр тодорхойлогдох тул дэлгэц нарийсах тусам багана цөөрнө.
2. **Жагсаалтын горим -> Grid горим**：Дэлгэцийн өргөн 380px-ээс бага (хэт жижиг дэлгэцтэй төхөөрөмж) үед жагсаалтын горим автоматаар grid горим руу шилжиж, картын агуулгын уншигдах байдлыг хангана.
3. **Хоёр тал -> Нэг тал**：Дэлгэцийн өргөн 1280px-ээс бага үед `tabletSidebar` тохиргооны дагуу нэг талын хажуугийн самбарыг харуулж, нэг хажуугийн самбарыг нуух ба өгүүллийн гарчгийн навигаци нь хөвөгч гарчгийн навигаци болж солигдоно.

## Тавдугаар хэсэг, түгээмэл асуулт

### А1: Grid баганын тоог хэрхэн тохируулах вэ?

**Х**: `columnWidth`-аар картын хамгийн бага өргөнийг тохируулахад хангалттай. Утга бага байх тусам ижил өргөнд багана олон, утга их байх тусам багана цөөн болно. Хөтөч боломжтой өргөнөөс хамааран хамгийн тохиромжтой баганын тоог автоматаар тооцоолно.

---

## Зургадугаар хэсэг, дүгнэлт

Firefly-ийн байрлалын систем танд илүү их эрх чөлөө олгож, энгийн тохиргоогоор хэрэгжүүлэх боломжтой.

Бид танд агуулгын төрөл болон зорилтот уншигчдын төхөөрөмжийн сонголтод тулгуурлан өөр өөр хослолыг туршиж, өөрт хамгийн тохирох блогийн хэлбэрийг олохыг зөвлөж байна.
