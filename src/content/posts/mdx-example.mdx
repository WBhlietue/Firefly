[Firefly](https://github.com/CuteLeaf/Firefly) нь `MDX` болон `Markdown` гэсэн хоёр төрлийн өгүүллийг дэмжих бөгөөд өгүүлэл дотор хоёр форматыг холимог ашиглаж болно. Хэт төвөгтэй агуулга, шаардлага байхгүй бол Markdown формат хангалттай гэж зөвлөж байна.
:::

## Markdown болон MDX-ийн ялгаа
- Markdown (MD) нь хөнгөн жингийн тэмдэглэгээний хэл бөгөөд хэрэглэгч цэвэр текстийн форматаар баримт бичиж, дараа нь форматад орсон HTML-д хөрвүүлэх боломжийг олгоно. Энгийн, хэрэглэхэд хялбар синтаксоороо өргөн хүлээн зөвшөөрөгдсөн бөгөөд баримт бичиг болон блогын өгүүлэл бичихэд онцгой тохиромжтой.
- MDX нь Markdown синтаксийг өргөтгөсөн формат бөгөөд Markdown баримт бичиг дотор JSX кодыг оёж оруулах боломжийг олгоно. MDX-ээр хэрэглэгч баримт бичиг дотор React компонентуудыг суулгаж, илүү баялаг интерактив байдал, динамикийг бий болгоно.

| Онцлог | Markdown | MDX |
| :--- | :--- | :--- |
| Үндсэн синтакс | Дэмжинэ (CommonMark) | Дэмжинэ (CommonMark) |
| HTML шошго | Дэмжинэ | Дэмжинэ (JSX хэлбэрээр) |
| Компонент import | Дэмжихгүй | Дэмжинэ (import) |
| Динамик өгөгдөл | Дэмжихгүй | Дэмжинэ (JS илэрхийлэл) |
| Стилийн тохиргоо | Хязгаарлагдмал (class/style) | Уян хатан (className/CSS-in-JS) |

## Firefly-ийн суурилуулсан тусгай MDX UI компонентууд
Энд Firefly-д суурилуулсан MDX UI компонентуудыг жагсаасан бөгөөд MDX өгүүлэлд шууд ашиглах боломжтой.

### Tab бүлэг: `TabGroup`
Сольж болох tab үүсгэхэд ашиглах бөгөөд өгүүлэлд өөр хэл эсвэл өөр хувилбарын кодыг харуулахад тохиромжтой.
````mdx
<TabGroup labels={["test.js", "test.py"]} client:load>
  ```js
  console.log(1)
  ```

  ```py
  print("hello world")
  ```
</TabGroup>
````

### Цаг хугацааны шугам: `Timeline` / `TimelineItem`

| Шинж чанар | Заавал | Тайлбар |
| :--- | :--- | :--- |
| `date` | Үгүй | Цаг хугацааны шошго, жишээ нь "2024-03-10" |
| `title` | Үгүй | Бичлэгийн гарчиг |
| `type` | Үгүй | Зангилааны өнгө, default нь сэдвийн өнгө, бусад нь анхааруулах хайрцгийн өнгөний багц (tip / note / important / warning / caution) |
| `icon` | Үгүй | Суурилуулсан icon нэр, цэгийн дотор харагдана: star / rocket / git / flag / book / heart / zap / bug / tag / calendar / code / edit |
| Үндсэн хэсэг | Үгүй | `<TimelineItem>` шошгон доторх агуулга, Markdown дэмжинэ |

```mdx
<Timeline>
  <TimelineItem date="2026-08-16" title="Шинэ хувилбар гарлаа" icon="rocket">
    Цоо шинэ хувилбар гаргаж, дараах шинэчлэлтүүдийг авчирлаа:

    - Цаг хугацааны шугамын компонент нэмэгдсэн
    - Харанхуй сэдэв сайжирсан

    Үндсэн хэсэгт **Markdown** агуулга дэмжигдэнэ.
  </TimelineItem>
  <TimelineItem date="2025-11-02" title="Сайт нээгдлээ" type="tip" icon="flag">
    Миний блогт тавтай морил.
  </TimelineItem>
  <TimelineItem date="2025-06-15" title="Төсөл эхэллээ" type="note">
    Firefly загварыг төлөвлөж эхэлсэн.
  </TimelineItem>
</Timeline>
```

### Алхмын мөр: `Steps` / `StepItem`

Дугаарласан алхмын мөр, заавар, deploy-ийн урсгалд тохиромжтой. Дугаар автоматаар үүсдэг тул гараар дарааллын дугаар оруулах шаардлагагүй.

| Шинж чанар | Заавал | Тайлбар |
| :--- | :--- | :--- |
| `title` | Үгүй | Алхмын гарчиг |
| `type` | Үгүй | Дугаарласан тойргийн өнгө, default нь сэдвийн өнгө, бусад нь анхааруулах хайрцгийн өнгөний багц (tip / note / important / warning / caution) |
| `icon` | Үгүй | Суурилуулсан icon нэр, icon байвал тооны оронд icon харагдана (star / rocket / git / flag / book / heart / zap / bug / tag / calendar / code / edit) |
| Үндсэн хэсэг | Үгүй | `<StepItem>` шошгон доторх агуулга, Markdown дэмжинэ |

```mdx
<Steps>
  <StepItem title="Хамаарлыг суулгах">
    `pnpm install` ажиллуулна.
  </StepItem>
  <StepItem title="Хөгжүүлэлтийн серверийг эхлүүлэх" type="tip" icon="rocket">
    `pnpm dev` ажиллуулж, `localhost:4321`-ийг нээнэ.
  </StepItem>
  <StepItem title="Өгүүлэл бичих">
    `src/content/posts/` дотор шинэ `.mdx` өгүүлэл үүсгэнэ.
  </StepItem>
</Steps>
```
